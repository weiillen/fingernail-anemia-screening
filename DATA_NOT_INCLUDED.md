# Data Not Included

This public portfolio repository intentionally omits the project CSV data and local file inventories from the uploaded source archive.

| Original file | Why it is omitted |
|---|---|
| `PredictingAnemiaInCo-CJStudyData_DATA_2023-07-12_0653.csv` | Contains subject-level clinical fields such as record ID, HCT, HGB, age, and race. |
| `Race and gender file 070425.csv` | Contains subject-level demographic fields including record ID, sex, race, and ethnicity. |
| `excluded.csv` | Contains participant-coded image filenames plus absolute local filesystem paths and project review metadata. |
| `inventory_saved.csv` | Contains participant-coded image filenames and absolute local filesystem paths. |

The raw fingernail images and segmentation annotations were also not present in the uploaded portfolio archive.

These omissions are for privacy/data-governance reasons and do not modify the submitted notebooks. Anyone reproducing the project should use data they are authorized to access and point the notebooks to their own local copies.
